# H5 适配优化 - Proposal

**创建日期**: 2026-04-09
**变更**: h5-adaptation
**版本**: v1.0

---

## 1. 概述

对 H5 周报系统的 5 个主流程页面进行移动端适配优化，确保触控操作友好、布局响应式。

### 1.1 背景

当前系统主要面向桌面端设计，在移动设备上存在以下问题：
- 按钮触控区域不足（< 44px）
- 侧边栏在小屏挤压内容
- 弹窗超出屏幕
- 间距过密不适合触控

### 1.2 目标

- 触控区域 ≥ 44px
- 无横向滚动
- 桌面端功能完全不受影响

## 3. 技术方案

### 3.1 渐进增强策略

- **桌面端** (≥ 768px)：保持现有布局和功能
- **移动端** (< 768px)：通过 CSS 媒体查询应用样式调整
- **不破坏**：现有功能完全不受影响

### 3.2 响应式断点

| 断点 | 宽度 | 生效样式 |
|------|------|----------|
| Mobile | < 480px | 归类编辑全屏弹窗 |
| Tablet/Mobile | < 768px | 所有 H5 适配 |

### 3.3 技术要求

- 纯 CSS 实现，不引入新依赖
- iOS 表单输入 `font-size: 16px` 防止缩放
- Drawer 使用 `Teleport` 确保弹层正确

---

## 4. 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 样式覆盖破坏桌面端 | 高 | 所有 H5 样式嵌套在 `@media` 中 |
| iOS 自动缩放 | 中 | 表单输入 `font-size: 16px` |
| 第三方组件样式冲突 | 低 | 使用 `:deep()` 穿透 |
