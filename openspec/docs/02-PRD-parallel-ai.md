# PRD：AI 并行化与页面多余内容优化

## 1. 产品流程变更

### 1.1 上传与解析流程
1. 用户上传文件。
2. 系统切换到解析模式，启动并发请求。
3. 页面底部的“核心功能”区块动画消失，提升视觉沉浸感。
4. 进度条根据并发任务的完成情况更新。

### 1.2 数据预览阶段
1. 用户点击“开始归类”。
2. 并发归类逻辑启动，显示解析进度。

## 2. 界面原型修改说明

### 2.1 首页 (HomePage)
- **状态 A (初始)**：显示上传区 + 流程指示器 + 核心功能介绍。
- **状态 B (已上传)**：显示数据预览区 + 流程指示器；**隐藏核心功能介绍**。

## 3. 用户体验优化点
- 减少无用的滚动，让核心操作区域始终在视野内。
- 缩短用户等待 AI 返回结果的时间。
