# 需求说明 - H5 周报系统

**创建时间**: 2026-03-28  
**版本**: v1.1  
**状态**: ✅ 已确认（2026-03-29）  
**项目**: H5 周报生成与编辑系统

---

## 1. 项目背景

### 1.1 用户场景
老馒头是 IT 技术管理者，管理团队包括多个产品组（SHOP 组、ERP 组、WMS 组等）。每周需要：
1. 收集团队成员填写的 Excel 周报
2. 基于上周模板生成本周周报
3. 在手机或电脑上编辑完善
4. 导出为 Markdown 格式（本周周报.md）发送

### 1.2 当前痛点
- ❌ Excel 内容分散，整理耗时
- ❌ 每周手动复制模板，容易遗漏章节
- ❌ 手机编辑不方便
- ❌ 格式不统一，花费时间在排版上

### 1.3 目标
- ✅ 上传 Excel 自动解析
- ✅ 基于模板自动生成周报结构
- ✅ 支持手机/电脑编辑
- ✅ 一键导出 Markdown（本周周报.md）

## 2. 输入数据

### 2.1 Excel 格式（✅ 已确认）

**文件名示例**: `产品周例会信息同步.xlsx`

**Sheet 结构**:
- Sheet 数量：1 个（Sheet1）
- 列名：`会议时间点 `、` 产品组 `、` 同步信息内容`

**核心字段**：

| 列名 | 说明 | 示例 |
|------|------|------|
| 会议时间点 | 日期 | 3.27 |
| 产品组 | 团队分组 | SALES 组、ERP 组、卡册、如意、C 网、三方对接 |
| 同步信息内容 | Markdown 格式的详细内容 | 来福商城优化... |

**Excel 格式**: 固定格式，每周相同结构

### 2.2 数据映射逻辑（✅ 已确认）

| Excel 产品组 | 周报表章节 | Excel 中的标题 | 说明 |
|-------------|-----------|--------------|------|
| SHOP 组 | 1. 来福商城 | 来福，卡册，如意，C 网 | 内部商城项目 |
| SHOP 组 | 2. 三方项目 | 三方对接 | 三方对接项目 |
| ERP 组 | 3. 采购与集采管理 | 采购管理，集采 | 采购相关 |
| ERP 组 | 4. 三方供应链 | 三方供应链 | 三方供应链 |
| ERP 组 | 5. 销售与财务管理 | 销售管理，异常单，财务管理 | 销售财务 |
| ERP 组 | 6. 竞价平台与异常单 | 竞价平台，异常单 | 特别项目 |
| WMS 组 | 7. 履约监控与物流一体化 | 履约监控 | WMSX 履约 |

**映射规则**:
- `产品组` → 章节标题/部门分类
- `同步信息内容` → 章节内容（Markdown）
- `会议时间点` → 周报日期/进度标签

### 2.3 上周模板（✅ 已确认）

**格式**: Markdown (.md)

**结构**: 7 个固定章节
1. 来福商城
2. 三方项目 (开发中)
3. 采购与集采管理
4. 三方供应链
5. 销售与财务管理
6. 竞价平台与异常单
7. 履约监控与物流一体化

**生成逻辑**:
- 读取 MD 文件
- 提取章节标题
- 已上线和开发中的结构也需要
- 用这个结构生成本周模板
- 内容从 Excel 填充

**状态标签**:
- `[完结]` / `【完结】` - 已完成
- `[无变更]` - 进度正常
- `[变更]` - 有变更
- `[新增]` - 新增需求
- `已上线 `、`开发中 `、` 测试中`、` 联调中`、` 已评审待排期 `、` 需求待输出`、` 延期风险`

## 3. 核心功能需求（✅ 已确认）

### 3.1 Excel 上传与解析
- 支持拖拽上传 `.xlsx` 文件
- 支持点击选择文件
- 自动读取 Sheet1
- 解析三列数据：时间、产品组、内容
- 显示解析结果预览
- 数据映射：根据产品组自动分配到 7 个章节

### 3.2 模板上传与生成
- 上传上周模板（Markdown）
- 提取 7 个章节结构
- 保持章节顺序
- 根据 Excel 内容填充各章节
- 自动识别状态标签

### 3.3 在线编辑
- **编辑器选型**: Quill（轻量 ~50KB，移动端友好）
- **编辑模式**: Markdown 编辑
- **实时预览**: 支持
- **数据来源**: 半自动（Excel 解析后预填充 + 手动补充）
- **自动保存**: 定时保存（每 30 秒），防丢失
- **内容类型**: Markdown 格式文本

### 3.4 导出功能
- **导出格式**: Markdown (.md)
- **文件名**: `本周周报.md`
- **用途**: 口头汇报 + 存档
- **优先级**: MVP 只做 Markdown，Word/PDF 后续迭代
