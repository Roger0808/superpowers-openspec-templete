# 需求说明：AI 并行化与页面多余内容优化

## 1. 功能需求

### 1.1 并发解析 (Parallel AI Parsing)
- **批量解析并发控制**：系统必须支持多个 LLM 请求并发执行。
- **并发阈值配置**：最大并发数默认为 3，支持在配置中调整。
- **进度实时反馈**：进度条需根据已完成的请求数占总请求数的比例进行平滑更新。
- **失败容错**：单个请求失败不应中断整体批处理任务，需记录失败项。

### 1.2 UI 内容净化 (UI Optimization)
- **彻底移除引导内容**：直接从 `HomePage.vue` 中删除底部的“核心功能”介绍区块，释放页面空间。
- **首页代码重构**：将 `HomePage.vue` 中的逻辑块（如上传、进度条）拆分为独立组件。
- **响应式优化**：确保步骤指示器在移动端有更好的布局表现。

## 2. 非功能需求

### 2.1 性能
- 解析效率提升：对于包含 20 条以上数据的 Excel，整体解析耗时应减少 50% 以上。

### 2.2 可维护性
- 减少 `HomePage.vue` 的文件行数，从目前的 1100+ 行减少到 600 行以内。
- 提取通用的并发控制工具类。

## 3. 验收标准
- [ ] 在 Network 面板中可见 API 请求是并发发出的（每次 3 个）。
- [ ] 上传文件后，页面下方的“核心功能”介绍区块消失。
- [ ] 所有的单元测试通过。
