# 需求说明 — 去除关键字模式

**创建日期**: 2026-04-17
**变更**: 去除关键字
**版本**: v1.0

---

## 1. 背景

系统当前支持两种归类模式：
- **keyword 模式**：基于关键字规则将 Excel 内容匹配到 7 个章节
- **llm 模式**（默认）：调用 MiniMax AI 进行智能过滤和章节归类

keyword 模式是早期方案，现已被 llm 模式完全替代。继续保留带来：
- 双路径维护成本
- 关键字硬编码难以扩展
- UI 切换按钮造成用户困惑

## 2. 需求

### 2.1 功能需求

- **移除** keyword 归类路径的所有代码
- **移除** UI 上的模式切换按钮（LLMModeToggle）
- **保留** AI 归类路径，行为不变
- **保留** AI 失败时的错误提示和重试机制

### 2.2 非功能需求

- 删除后代码零死代码（不留注释 fallback）
- 构建通过：`npm run build:check` 无错误
- 现有单元测试全部通过

### 2.3 不在本次范围

- AI 归类逻辑本身的任何改动
- 新的归类模式
- UI 样式调整

## 3. 成功标准

- [ ] 页面无「关键词」切换按钮
- [ ] Excel 上传后直接走 AI 归类流程
- [ ] AI 失败时显示错误提示，用户可重试
- [ ] `npm run build:check` 通过
- [ ] `npm test` 通过
