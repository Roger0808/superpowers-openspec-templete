# 需求调研清单 - H5 周报系统

**创建时间**: 2026-03-28  
**项目**: H5 周报生成与编辑系统  
**阶段**: Phase 0 - 需求调研

---

## ✅ 已知需求（来自老馒头）

### 核心场景
> "我想开发一个 H5 网站，用于写我的周报总结，每周我给你一份 excel，是我的团队成员写的，我还会给你我上周总结的周报模板，我需要你生成本周的模板，我想在手机或者电脑上去编辑。"

### 输入
- **Excel 文件**: 团队成员写的周报内容
- **上周模板**: 上周总结的周报模板

### 核心功能
- **模板生成**: 基于上周模板 + 本周 Excel，生成本周模板
- **编辑功能**: 支持手机和电脑编辑，并且最终导出文件“本周周报.md” 

### 项目目标
1. **验证 SDD 流程** - Superpowers + OpenSpec 在 Claude Code 中的工作模式
2. **交付可用系统** - 最终能给老馒头实际使用

## ✅ 已确认需求

### 一、Excel 格式相关（✅ 已确认 2026-03-29）

**Q1. Excel 的具体结构是什么？** ✅
- Sheet 数量：1 个
- Sheet 名称：Sheet1
- 列名：`会议时间点 `、` 产品组 `、` 同步信息内容`
- 示例文件：产品周例会信息同步.xlsx

**Q2. 团队成员填写的内容包含哪些字段？** ✅
- 产品组（如：SALES 组、ERP 组、卡册、如意、C 网、三方对接...）
- 同步信息内容（Markdown 格式的详细工作内容）
- 会议时间点（如：3.27）

**Q3. Excel 的格式是否固定？** ✅
- 答案：固定格式，每周相同结构

**数据映射逻辑** ✅：
- `产品组` → 章节标题/部门分类
- `同步信息内容` → 章节内容（Markdown）
- `会议时间点` → 周报日期/进度标签

| ERP 组     | 3. 采购与集采管理    | 采购管理，集采       | 采购相关    |

| ERP 组     | 5. 销售与财务管理    | 销售管理，异常单，财务管理 | 销售财务    |

### 二、周报模板相关（✅ 已确认 2026-03-29）

**Q4. 周报模板的结构是什么？** ✅
- 答案：7 个固定章节（来福商城、三方项目、采购与集采管理、三方供应链、销售与财务管理、竞价平台与异常单、履约监控与物流一体化）

**Q5. 模板的格式是什么？** ✅
- 答案：Markdown (.md)

**Q6. "生成本周模板"的具体逻辑是什么？** ✅
- 答案：**方案 A - 仅提取章节结构**
- 读取 MD 文件
- 提取章节标题
- 已上线和开发中的结构也需要
- 用这个结构生成本周模板
- 内容从 Excel 填充

**Q7. 章节是固定的还是可配置的？** ✅
- 答案：**方案 A - 固定 7 章节**
- 章节名称写死在代码中
- 不可修改
- 简单快速（MVP 方案）
