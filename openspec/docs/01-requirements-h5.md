# 需求说明 - H5 适配优化

**创建日期**: 2026-04-09
**阶段**: Requirements
**迭代**: 二次迭代 - H5 适配优化

---

## 1. 目标

对项目 5 个主流程页面进行 H5 适配优化，确保在移动设备上的可用性。

---

## 2. 成功标准

| 标准 | 要求 |
|------|------|
| 触控区域 | ≥ 44px |
| 文字可读 | 正文 ≥ 12px |
| 无横向滚动 | 100vw 内显示 |
| 桌面端兼容 | 功能完全不受影响 |

---

## 3. 5 个页面需求

### 3.1 首页 (HomePage)

**问题**：
- 按钮触控区域不足（36px < 44px）
- 上传区域边框太细
- 日期选择器间距过小

**需求**：
- 调整按钮高度至 44px
- 增大上传区域 padding
- 调整日期选择器间距

### 3.2 编辑页 (EditorPage)

**问题**：
- 双栏布局（200px 侧边栏 + 主内容区）在小屏挤压
- 7 章节导航在小屏换行
- 模式切换按钮过小

**需求**：
- 小屏隐藏侧边栏，改为抽屉式导航
- 顶部添加汉堡菜单按钮
- 点击汉堡菜单展开左侧抽屉

### 3.3 归类预览 (ClassificationPreview)

**问题**：
- 卡片网格 3 列在小屏太窄
- 过滤标签在小屏换行

**需求**：
- 使用 CSS grid auto-fill 实现响应式列数
- 过滤栏支持横向滚动

### 3.4 归类编辑 (ClassificationEditor)

**问题**：
- 弹窗宽度 500px 在小屏超出屏幕
- 表单元素过密

**需求**：
- 小屏（< 480px）使用全屏弹窗
- 增大表单元素间距
- 按钮高度 48px

### 3.5 导出面板 (ExportPanel)

**问题**：
- 格式选择卡片在小屏换行
- 导出按钮略小

**需求**：
- 格式卡片在小屏改为垂直堆叠
- 导出按钮高度 48px

---

## 4. 响应式断点

| 断点 | 宽度 | 生效样式 |
|------|------|----------|
| Mobile | < 480px | 归类编辑全屏弹窗 |
| Tablet | < 768px | 所有 H5 适配 |
| Desktop | ≥ 768px | 保持现有布局 |

---

## 5. 技术要求

### 5.1 CSS 要求
- 所有 H5 样式嵌套在 `@media (max-width: 768px)` 中
- 使用 `!important` 或更具体选择器确保生效
- iOS 表单输入添加 `font-size: 16px` 防止缩放

### 5.2 组件要求
- Drawer 抽屉组件：使用 `Teleport` 确保弹层正确渲染
- 保持现有组件的 props/emits 接口不变
