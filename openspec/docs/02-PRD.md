# 产品需求文档 (PRD) - H5 周报系统

**创建时间**: 2026-03-28  
**版本**: v1.1  
**状态**: ✅ 已确认（2026-03-29）  
**项目**: H5 周报生成与编辑系统

---

## 1. 产品概述

### 1.1 产品定位
一个轻量级的 H5 周报工具，帮助技术管理者快速整理团队周报，支持手机/电脑编辑，一键导出 Markdown（本周周报.md）。

### 1.2 目标用户
- **主要用户**: 老馒头（IT 技术管理者）
- **使用场景**: 每周一次，整理团队周报

### 1.3 核心价值
- ⏱️ **省时**: 自动解析 Excel，减少手动整理时间
- 📱 **便捷**: 支持手机编辑，随时随地完善周报
- 📋 **规范**: 保持固定模板结构，避免遗漏章节
- 📤 **高效**: 一键导出 Markdown（本周周报.md），直接发送

---

## 2. 功能架构

```
H5 周报系统
├── 首页
│   ├── Excel 上传区
│   ├── 模板上传区
│   └── 生成按钮
├── 编辑页
│   ├── 章节导航（7 个章节）
│   ├── Markdown 编辑器（Quill）
│   └── 导出按钮
└── 本地存储
    └── 定时自动保存（每 30 秒）
```

---

## 3. 详细功能设计（✅ 已确认）

### 3.1 首页

#### 3.1.1 Excel 上传区
**功能**:
- 拖拽上传或点击选择文件
- 支持格式：`.xlsx`
- 文件大小限制：< 10MB
- 解析后显示预览
- 数据映射：根据产品组自动分配到 7 个章节

**界面元素**:
```
┌─────────────────────────────────┐
│  📤 拖拽 Excel 文件到此处       │
│     或点击"选择文件"按钮        │
│                                 │
│  支持格式：.xlsx                │
│  文件大小：< 10MB               │
└─────────────────────────────────┘
```

#### 3.1.2 模板上传区
**功能**:
- 上传上周的周报模板（Markdown）
- 提取 7 个章节结构
- 显示模板预览

**生成逻辑**:
- 读取 MD 文件
- 提取章节标题
- 用这个结构生成本周模板
- 内容从 Excel 填充

### 3.2 编辑页

#### 3.2.1 章节导航
**功能**:
- 显示 7 个固定章节标题
- 点击跳转到对应章节
- 显示各章节状态（已编辑/未编辑）

**7 个章节**:
1. 来福商城
2. 三方项目 (开发中)
3. 采购与集采管理
4. 三方供应链
5. 销售与财务管理
6. 竞价平台与异常单
7. 履约监控与物流一体化

#### 3.2.2 Markdown 编辑器
**编辑器选型**: Quill
- 轻量（~50KB）
- 功能够用
- 移动端友好

**功能**:
- 支持 Markdown 语法
- 实时预览
- 加粗、斜体、列表等基础格式
- 自动保存（每 30 秒）

**数据来源**: 半自动
- Excel 解析后预填充
- 支持手动补充

### 3.3 导出功能

**导出格式**: Markdown (.md)  
**文件名**: {{YY-MM-DD}}.md`  
**用途**: 口头汇报 + 存档  
**优先级**: MVP 只做 Markdown，Word/PDF 后续迭代

## 4. 数据映射逻辑（✅ 已确认）

### 4.1 Excel 到周报的映射关系

| Excel 产品组 | 周报表章节         | Excel 中的标题    | 说明     |
| --------- | ------------- | ------------- | ------ |
| SALES组    | 1. 来福商城       | 来福，卡册，如意，C 网  | 内部商城项目 |
| SALES组    | 2. 三方项目       | 三方对接          | 三方对接项目 |
| ERP组      | 3. 采购与集采管理    | 采购管理，集采       | 采购相关   |
| ERP组      | 4. 三方供应链      | 三方供应链         | 三方供应链  |
| ERP组      | 5. 销售与财务管理    | 销售管理，异常单，财务管理 | 销售财务   |
| ERP组      | 6. 竞价平台与异常单   | 竞价平台，异常单      | 特别项目   |
| WMS组      | 7. 履约监控与物流一体化 | 履约监控          | WMSX履约 |

### 4.2 状态标签处理

**自动识别的标签**:
- `[完结]` / `【完结】` - 已完成
- `[无变更]` - 进度正常
- `[变更]` - 有变更
- `[新增]` - 新增需求
- `已上线 `、`开发中 `、` 测试中`、` 联调中`、` 已评审待排期`

**处理方式**:
- 从 Excel 内容中自动识别
- 在编辑页面支持手动修改
