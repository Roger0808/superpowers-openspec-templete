# 技术部飞书周报生成技能 (weekly-report-feishu-manual)

全手动模式的技术部周报生成技能，直接从飞书电子表格读取数据，使用 AI 能力智能分类并生成产品周报。

## 功能特性

- 📊 **飞书数据源**: 直接从飞书电子表格读取数据，无需导出 Excel
- 🤖 **AI 分类**: 使用 AI 能力直接分类，无需外部 API
- 🎯 **智能过滤**: 自动过滤需求调研、下周计划、跟进中等无效内容
- 📋 **7大章节**: 自动归类到正确的业务章节
- 📁 **自动保存**: 自动保存为 Markdown 格式文件

## 前置依赖

- 需要安装 `lark-cli` 并登录飞书账号
- 需要有访问指定飞书文档的权限

## 飞书文档

永久飞书地址：https://ecn7j0rosx4k.feishu.cn/wiki/M6U4wxsl6iH6EJkO4Jxc2MtwnPf?sheet=bee36a

## 如何导入使用

### 方法一：直接复制（推荐）

1. 复制整个 `weekly-report-feishu-manual` 文件夹
2. 粘贴到你的项目或技能目录中的 `.trae/skills/` 或 `skills/` 文件夹下
3. 重启你的 AI 助手即可使用

### 方法二：手动创建

1. 在你的技能目录中创建 `weekly-report-feishu-manual` 文件夹
2. 复制 `SKILL.md` 到该文件夹
3. （可选）复制示例文件作为参考

## 使用方法

直接对 AI 助手说：
- "帮我生成周报"
- "写周报"
- "技术部周报"
- "飞书周报"
- "生成本周周报"

## 文件说明

- `SKILL.md` - 技能核心配置和规则
- `README.md` - 本文件，使用说明
- `examples/` - 示例输出（可选）

## 技能规则概览

### 7大业务章节

1. **来福商城与卡册** - SALES组
2. **三方对接项目** - SALES组
3. **采购与集采管理** - ERP组
4. **三方供应链** - ERP组
5. **销售与财务管理** - ERP组
6. **竞价平台与异常单** - ERP组
7. **履约监控与物流一体化** - **WMS组**

### 项目前缀规则

- 原文有前缀就保留原文的前缀，没有就不要自己硬加
- `【变更】`、`【新增】` 这两个前缀要去掉
- 保留 `【统一商品池】`、`【商品】`、`【集采】`、`【售后】`、`【品控&客服】`、`【异常单】`、`【一点通】`、`【竞价平台】` 等

### 状态识别

- **已完成**: 上线日期 ≤ 今天
- **开发中**: 上线日期 > 今天，或者有开发中等关键词

### 标题格式

- 主标题：`# 产品周报`
- 本周统计：`## 本周统计`
- 业务章节：`#### 章节名`（4个#）

## 输出位置
