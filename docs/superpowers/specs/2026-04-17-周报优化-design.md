# 周报优化 - 设计规范

**创建日期**: 2026-04-17
**版本**: v1.0

---

## 1. 概述

本次迭代对 H5 周报系统进行优化，主要涉及：章节重命名、流程简化、UI 简化、导出简化。

---

## 2. 章节重命名与归类合并

### 2.1 变更的章节

| chapterId | 原名称 | 新名称 |
|-----------|--------|--------|
| chapter-1 | 来福商城 | 来福商城与卡册 |
| chapter-2 | 三方项目 (开发中) | 三方对接项目 |

### 2.2 AI 归类 prompt 更新

**chapter-1 新描述**：
```
来福商城与卡册 (chapter-1) - 来福、卡册、如意、C网、会员系统、额度、转赠、促销
```

**chapter-2 新描述**：
```
三方对接项目 (chapter-2) - 三方对接、商城平台搭建、API对接
```

### 2.3 二级标题归类合并

Excel 中的二级标题（"一、来福"、"二、卡册"、"三、如意"、"四、C网"）全部归入 chapter-1（来福商城与卡册）。

---

## 3. 流程简化

### 3.1 新流程（6 步）

1. **上传Excel** → 2. **数据预览** → 3. **AI归类（自动）** → 4. **模板选择** → 5. **编辑页（Markdown）** → 6. **导出MD**

### 3.2 删除的步骤

- **归类预览**：删除此步骤，AI 归类完成后直接进入模板选择
- 用户点击"开始归类"后，系统自动完成归类，无需确认

---

## 4. 编辑页面改造

### 4.1 删除的功能

| 功能 | 文件/组件 |
|------|----------|
| 富文本编辑器（Quill） | Quill 编辑器组件及相关依赖 |
| 保存功能 | EditorPage.vue 中的保存逻辑 |
| Word 导出 | docx 相关代码 |
| PDF 导出 | html2pdf.js 相关代码 |

### 4.2 保留/新增的功能

| 功能 | 实现方式 |
|------|----------|
| Markdown 编辑 | CodeMirror 编辑器 |
| 导出 MD | 保留 markdown 导出逻辑 |

### 4.3 CodeMirror 配置

- 使用 CodeMirror 6（轻量级）
- 主题：轻量级默认主题
- 语言支持：Markdown
- 行号显示：关闭
- 移动端适配

---

## 5. 导出简化

### 5.1 删除的导出格式

- Word（.docx）
- PDF（.pdf）

### 5.2 保留的导出格式

- Markdown（.md）

### 5.3 导出逻辑

- 用户在编辑页修改 Markdown 内容后
- 点击"导出 MD"按钮
- 系统生成单个 md 文件供下载
